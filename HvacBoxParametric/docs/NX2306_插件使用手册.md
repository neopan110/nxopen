# HVAC箱体参数化插件 — NX2306使用手册

---

## 概述

本插件在NX2306中运行，通过输入参数自动生成完整的汽车空调HVAC箱体3D模型。

**功能**: 输入箱体尺寸、风门参数 → 自动生成壳体+风道+风门+密封+校验+工程图

---

## 安装（一次性，2分钟）

### 1. 确认文件

编译成功后，你应该有两个文件：
```
hvac_box_parametric.dll     ← 插件主程序
param_defaults.json         ← 默认参数配置
```

### 2. 复制到NX目录

将上述两个文件复制到：
```
C:\Siemens\NX2306\application\
```

> 💡 如果`application`文件夹不存在，手动创建它。

### 3. 完成

不需要其他配置，NX启动后即可使用。

---

## 使用方法

### 第一步：打开NX2306，新建Part

1. 启动NX2306
2. 文件 → 新建 → 模型 (Model)
3. 选择模板：空白模板(Blank)
4. 文件名输入如 `HVAC_Box_Assembly.prt`
5. 确定

### 第二步：运行插件

1. 菜单栏 → **文件(File)** → **执行(Execute)** → **NX Open**
2. 在弹出的文件对话框中，导航到：
```
C:\Siemens\NX2306\application\hvac_box_parametric.dll
```
3. 选中该dll文件 → **确定(OK)**

### 第三步：选择参数模式

弹出对话框询问：
```
Use default parameters?
YES = Build with defaults
NO = Input custom parameters
```

- 点 **"Use Defaults"**: 使用默认参数直接生成（快速体验）
- 点 **"Custom Input"**: 逐个输入你的设计参数

### 第四步：输入参数（如果选了Custom）

系统会依次弹出以下参数输入框：

| 参数 | 含义 | 默认值 | 范围 |
|------|------|--------|------|
| Box Length X | 箱体总长度 | 420mm | 350~500 |
| Box Width Y | 箱体总宽度 | 320mm | 280~400 |
| Box Height Z | 箱体总高度 | 260mm | 200~320 |
| Wall Thickness | 壁厚 | 2.5mm | 2.0~3.5 |
| Heater Tilt Angle | 加热器倾角 | 0° (竖置) | 0~75 |
| Core Spacing | 蒸发器到加热器间距 | 90mm | 60~120 |
| Parting Plane Z | 分型面高度 | 130mm | 高度的40%~60% |

每个框输入数值后点确定，输入完最后一个自动开始生成。

> 如果输入了超出范围的值，会弹出警告，你可以修正。

### 第五步：等待生成

- 进度显示在NX的信息窗口(Listing Window)中
- 整个过程约10~30秒
- 完成后弹出结果报告对话框

### 第六步：查看结果

生成完成后，NX图形窗口中会显示完整的箱体3D模型：
- 上壳体 + 下壳体（已分割）
- 内部风道空腔
- 芯体安装导轨
- 鼓风机法兰
- 出风口法兰
- 密封槽
- 加强筋
- 执行器安装座

**Listing Window** 中会显示详细报告：

## 修改参数后重新生成

如果想修改参数重新生成：

1. **Ctrl+Z** 撤销当前模型（或关闭不保存，重新新建Part）
2. 重新执行插件（文件→执行→NX Open→选dll）
3. 输入新参数

---

## 修改默认参数

如果你想永久修改默认参数值（避免每次手输）：

1. 用**记事本**打开：
```
C:\Siemens\NX2306\application\param_defaults.json
```

2. 修改对应数值，例如把箱体长度改为450：
```json
"boxLengthX": 450.0,
```

3. 保存文件

4. 下次运行插件选"Use Defaults"时就会使用新值

---

## NX表达式查看

生成成功后，模型中会自动创建NX表达式(Expression)，名称以`HVAC_L1_`开头：

工具 → 表达式(Expressions) 可以看到：
```
HVAC_L1_boxLengthX = 420
HVAC_L1_boxWidthY = 320
HVAC_L1_wallThickness = 2.5
...
```

你可以直接在NX表达式编辑器中修改这些值，然后手动更新模型。

## 故障排除

| 问题 | 解决方法 |
|------|---------|
| 找不到dll文件 | 确认复制到了`NX2306\application\`目录 |
| 运行后NX崩溃 | 确认用VS2019编译(非VS2022)，且为Release模式 |
| 弹出"No work part"错误 | 先新建或打开一个Part文件再运行 |
| 生成后模型是空的 | 检查Listing Window中的错误信息 |
| 参数超出范围警告 | 按提示修改为合理范围内的值 |
| 校验FAIL | 查看Listing Window中的具体失败项和建议 |

## 高级用法

### 注册为NX菜单项

如果想在NX菜单栏中添加专用按钮（避免每次走 File→Execute 路径）：

1. 创建文件 `hvac_box.men`：
```
VERSION 200
MENUBAR_ITEM 1
BUTTON HVAC_BOX_BUILD
LABEL HVAC Box Builder
LIBRARIES hvac_box_parametric.dll
LIBRARY_TYPE USER_FUNCTION
```

2. 放到 `C:\Siemens\NX2306\application\`

3. 重启NX，菜单栏会出现"HVAC Box Builder"按钮
