# Visual Studio 2019 Community 安装指南

> 编译HVAC箱体参数化插件需要VS2019。本指南从零开始，5分钟完成。

---

## 第一步：下载VS2019 Community（免费）

**下载地址**：
https://visualstudio.microsoft.com/vs/older-downloads/

1. 打开上述网址
2. 找到 **Visual Studio 2019** 区域
3. 点击 **Community** 版本的 "下载" 按钮
4. 保存 `vs_community.exe` 到桌面

> ⚠️ **必须是2019版本！不要下载2022版！**（NX2306与VS2022不兼容，PIT-011）

---

## 第二步：安装（选择工作负载）

1. 双击运行 `vs_community.exe`
2. 等待安装程序初始化（约1分钟）
3. 在"工作负载"页面，**只需要勾选一个**：

```
☑ 使用C++的桌面开发 (Desktop development with C++)
```

4. 在右侧"安装详细信息"中，确认以下组件已勾选：
```
☑ MSVC v142 - VS 2019 C++ x64/x86 build tools
☑ Windows 10 SDK (任一版本)
☑ 用于CMake的C++ CMake工具
```

5. 点击 **安装**
6. 等待下载和安装完成（约10-20分钟，取决于网速）

---

## 第三步：设置NX环境变量

安装完VS2019后，需要告诉编译器NX2306在哪里：

### 方法A：永久设置（推荐）

1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
2. 在"系统变量"中点击"新建"：
```
变量名: UGII_BASE_DIR
变量值: C:\Siemens\NX2306
```
（如果你的NX安装在其他路径，请修改变量值）

3. 点击确定保存

### 方法B：临时设置（每次编译前执行）

打开命令提示符，输入：
```
set UGII_BASE_DIR=C:\Siemens\NX2306
```

---

## 第四步：编译插件

1. 打开"文件资源管理器"，进入插件源码目录：
```
HvacBoxParametric\
```

2. **双击 `build.bat`**

3. 等待编译完成（首次约1-2分钟）

4. 看到以下信息表示成功：
```
==========================================
  BUILD SUCCESSFUL!
==========================================
Output: ...\build\bin\hvac_box_parametric.dll
```

5. 脚本会问是否自动复制到NX目录，输入 `Y` 回车

---

## 常见问题

### Q: "CMake not found"
**A**: 安装VS2019时没有勾选"CMake工具"。重新运行VS安装程序，添加该组件。
或者单独安装CMake：https://cmake.org/download/

### Q: "UGII_BASE_DIR not set"
**A**: 环境变量没设置。按第三步操作，或者在build.bat开头加一行：
```
set UGII_BASE_DIR=C:\Siemens\NX2306
```

### Q: 编译报错 "cannot open file libufun.lib"
**A**: UGII_BASE_DIR路径不对。确认该目录下存在 `NXBIN\libufun.lib` 文件。

### Q: 编译报错 "C2065 undeclared identifier"
**A**: NX UGOPEN头文件路径有问题。确认 `%UGII_BASE_DIR%\UGOPEN\uf.h` 存在。

## 验证安装成功

如果以上步骤全部完成且build.bat显示成功，你已经拥有了：
```
%UGII_BASE_DIR%\application\hvac_box_parametric.dll    ← 插件
%UGII_BASE_DIR%\application\param_defaults.json        ← 配置
```

接下来请参照《NX2306插件使用手册》在NX中运行。
