# 从零开始：下载代码 → 编译 → 部署到NX2306 完整教程

> 假设你已经完成了VS2019安装和环境变量设置（步骤1和2）。
> 本教程从"怎么把代码弄到电脑上"开始，一直到"在NX里点击运行"。

---

## 步骤3：从GitHub下载代码

### 方法A：直接下载ZIP压缩包（最简单，推荐）

1. **打开浏览器**，访问：
```
https://github.com/neopan110/nxopen/tree/feature/hvac-parametric-architecture
```

2. **点击绿色的 "Code" 按钮**（页面右侧偏上位置）

3. 在下拉菜单中，点击 **"Download ZIP"**

4. 浏览器会下载一个文件：`nxopen-feature-hvac-parametric-architecture.zip`
   - 保存位置：你的"下载"文件夹

5. **解压ZIP文件**：
   - 右键点击下载的zip文件
   - 选择 "解压到当前文件夹" 或 "解压到..."
   - 你会得到一个文件夹：`nxopen-feature-hvac-parametric-architecture`

6. **进入到插件代码目录**：
```
nxopen-feature-hvac-parametric-architecture\HvacBoxParametric\
```

**这个 `HvacBoxParametric` 文件夹就是你需要的全部代码。**

7. **（推荐）把它复制到一个简短路径**，例如：
```
D:\HVAC\HvacBoxParametric\
```
> 为什么？因为路径太长（含中文或空格）可能导致编译失败。

---

### 方法B：用Git命令克隆（如果你装了Git）

如果你的电脑装了Git（不确定就用方法A）：

1. 在你想放代码的位置（如 `D:\HVAC\`），右键 → "Git Bash Here"

2. 输入以下命令：
```bash
git clone -b feature/hvac-parametric-architecture https://github.com/neopan110/nxopen.git
```

3. 等待下载完成，代码在：
```
D:\HVAC\nxopen\HvacBoxParametric\
```

---

### 下载完成后，确认目录结构正确

打开 `HvacBoxParametric` 文件夹，你应该看到：

```
HvacBoxParametric\

├── CMakeLists.txt
├── config\
│   └── param_defaults.json
├── docs\
├── include\

│   ├── modules\

```

**如果你能看到 `build.bat` 文件，说明下载正确。**

## 步骤4：双击编译

### 4.1 确认环境变量已设置

在开始编译之前，确认一下环境变量：

1. 按 `Win+R`，输入 `cmd`，回车，打开命令提示符
2. 输入：
```
echo %UGII_BASE_DIR%
```
3. 应该显示类似：
```
C:\Siemens\NX2306
```

**如果显示 `%UGII_BASE_DIR%`（原样输出），说明环境变量没设好，回去设置。**

> 设置方法：右键"此电脑" → 属性 → 高级系统设置 → 环境变量 → 系统变量 → 新建：
> - 变量名：`UGII_BASE_DIR`
> - 变量值：`C:\Siemens\NX2306`（改成你实际的NX安装路径）
> 
> 设置完后**必须重启命令提示符**才生效。

### 4.2 双击 build.bat

1. **在文件资源管理器中**，进入 `HvacBoxParametric` 文件夹

2. **找到 `build.bat` 文件**

3. **双击它**

4. 弹出黑色命令行窗口，显示编译过程：


5. **关键看这一行**：
```

```
看到这个就说明**编译成功了**！

### 4.3 如果编译失败怎么办

**看黑色窗口里的红色/黄色错误信息**：

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| `UGII_BASE_DIR not set` | 环境变量没设 | 按4.1设置 |
| `VS2019 not found` | VS2019没装好 | 重新安装VS2019 |
| `CMake not found` | 没装CMake组件 | VS安装器里勾选"CMake工具" |
| `cannot open file libufun.lib` | NX路径不对 | 检查UGII_BASE_DIR路径 |
| `cannot open include file: uf.h` | NX UGOPEN目录不存在 | 确认NX安装完整 |

## 步骤5：部署到NX（把dll放进去）

### 5.1 自动部署（build.bat最后会问你）

编译成功后，脚本会问你：
```
Auto-copy to NX application folder? (Y/N):
```

**输入 `Y` 然后按回车**。

脚本会自动把两个文件复制到NX目录：
```
已复制: hvac_box_parametric.dll → C:\Siemens\NX2306\application\
已复制: param_defaults.json     → C:\Siemens\NX2306\application\
```

**这就完成了！**

### 5.2 手动部署（如果自动复制失败）

如果自动复制报错（比如权限不够），手动操作：

**需要复制的文件（2个）**：

| 源文件位置 | 目标位置 |
|-----------|---------|
| `HvacBoxParametric\build\bin\hvac_box_parametric.dll` | `C:\Siemens\NX2306\application\` |
| `HvacBoxParametric\config\param_defaults.json` | `C:\Siemens\NX2306\application\` |

操作步骤：

1. 打开文件资源管理器，进入：
```
你的代码目录\HvacBoxParametric\build\bin\
```

2. 找到 `hvac_box_parametric.dll` → **右键 → 复制**

3. 进入NX目录：
```
C:\Siemens\NX2306\application\
```
> 如果 `application` 文件夹不存在，**右键 → 新建 → 文件夹** → 命名为 `application`

4. **右键 → 粘贴**

5. 回到代码目录，进入：
```
你的代码目录\HvacBoxParametric\config\
```

6. 找到 `param_defaults.json` → **右键 → 复制**

7. 粘贴到同一个 `application` 文件夹中

### 5.3 确认部署成功

打开 `C:\Siemens\NX2306\application\`，确认里面有这两个文件：
```
C:\Siemens\NX2306\application\
├── hvac_box_parametric.dll     ← 14KB左右
└── param_defaults.json         ← 1KB左右
```

**两个文件都在 = 部署完成！**

## 验证：在NX2306中运行

1. **启动NX2306**
2. **文件 → 新建 → 模型 → 确定**（创建一个空Part）
3. **文件 → 执行 → NX Open**
4. 在弹出的文件选择框中，导航到：
```
C:\Siemens\NX2306\application\
```
5. 选中 `hvac_box_parametric.dll` → **确定**
6. 弹出参数对话框 → 选择 "Use Defaults" → 等待生成
7. **看到3D箱体模型出现 = 全部成功！** 🎉

## 后续修改参数重新生成

每次修改代码后需要重新编译：
- 双击 `build.bat` → 输入 `Y` → 重启NX → 重新执行

如果只是修改**默认参数值**（不改代码）：
- 用记事本打开 `C:\Siemens\NX2306\application\param_defaults.json`
- 改数值 → 保存
- NX中重新执行dll即可（不需要重新编译）
